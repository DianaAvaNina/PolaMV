# MV-CH050-10UP 真机验收清单

状态：待接机执行，不能由模拟测试替代。

1. **设备与驱动**：在官方 MVS 中确认识别型号、序列号和 USB 3.0 连接，关闭 MVS 后在 PolaMV 搜索打开；重复开关 10 次，不残留独占句柄。
2. **参数**：逐个检查曝光、增益的上下限以及合法/非法输入；核对设置后的实际读回值。测试停止状态和运行状态修改。对比自动曝光/增益的行为。
3. **像素格式**：遍历设备返回的 Mono8、Mono10、Mono10Packed/Mono10p、Mono12、Mono12Packed/Mono12p。使用固定曝光场景对比官方软件原始 TIFF 的尺寸、位深、有效范围及逐像素 DN。设备不返回的格式记为不适用。
4. **阵列与角度**：镜头前放已知方向线偏振片，在 RAW 图查看 2×2 原始强度；分别以水平、逆时针 45°、顺时针 45°、垂直确认最大强度位置。核对 AoLP 的 0、+45、−45、−90 周期边界。确认后由开发者固化底层排列；不要把当前参考排列当作实测结论。
5. **低信号**：逐渐减小光强，在三种位深下验证 Gray 低于 2%FS 时 AoLP/DoLP 成 NaN；Gray/RAW 不丢失。开启 5% DoLP 筛选，确认仅 AoLP 变为 NaN。
6. **触发**：连续采集；软件单次触发；按相机手册正确电平接入外触发。核对源、上升/下降沿、延时、输入去抖、Burst、Trigger Cache 等实际支持节点。没有信号时显示等待，拔线与断开设备应区别处理。
7. **保存**：先停止在已知 Frame ID 的帧，对四页分别手动保存，用 tifffile 或 MATLAB 验证数据类型、DN、NaN、AoLP 单位、DoLP 比例及元数据。移动/缩放不改变保存尺寸。相同前缀反复保存不覆盖。
8. **自动保存**：低频发送 10 个外触发，核对接收数、帧号、文件数；切换页面后检查后续保存类型。逐步提高频率观察队列能力。队列满或磁盘写入失败必须明确报错，记录失败帧号。软件触发和连续采集不能触发外部自动保存。
9. **性能**：在各格式、合适曝光及 USB 带宽下记录接收/处理/显示 FPS、帧号缺口、预览跳过、CPU、内存和磁盘。至少连续采集 30 分钟，分别测试保存和不保存。
10. **异常恢复**：拔掉 USB、重新插入、停止/关闭/重新搜索连接；测试无写权限目录和磁盘空间不足。退出前排空已接收的保存任务，不应残留损坏的最终 TIFF。

注意：设备端 ROI 起点、翻转、Binning 和 Decimation 可能改变阵列物理对应。本版本不主动限制这些节点，也未实现其偏振阵列自适应。进行基准验收应记录并使用相机原始完整阵列配置。
