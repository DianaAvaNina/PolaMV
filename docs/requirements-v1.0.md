# MV-CH050-10UP 偏振相机控制与分析软件需求规格书

**版本：V1.0**

## 1. 项目概述

开发一套用于海康机器人偏振相机 **MV-CH050-10UP** 的 Windows 桌面软件，实现相机控制、实时图像采集、偏振图像处理、数据显示和 TIFF 图像保存。

软件主要用于实验室偏振成像实验，应兼顾：

- 操作方便；
- 图像实时性；
- 偏振计算的定量性；
- 参数可追溯性；
- 外部触发实验的使用需求。

目标运行环境：

- Windows 10 64 bit；
- Windows 11 64 bit。

目标相机：

- HIKROBOT MV-CH050-10UP；
- Sony IMX250MZR 偏振图像传感器；
- 原始分辨率 2448 × 2048；
- USB 3.0 接口。

---

# 2. 软件总体功能

软件主要包含以下功能模块：

1. 相机连接与状态管理；
2. 相机基础参数设置；
3. 内部连续采集、软件触发和外部硬件触发；
4. RAW 偏振原始图像实时显示；
5. 全分辨率灰度图实时计算和显示；
6. 全分辨率线偏振角 AoLP 实时计算和显示；
7. 全分辨率线偏振度 DoLP 实时计算和显示；
8. 灰度直方图实时显示；
9. 鼠标位置像素信息查询；
10. 图像缩放和平移；
11. 实时帧率显示；
12. TIFF 图像保存；
13. 外部触发自动保存；
14. 软件参数保存和恢复。

# 3. 相机连接与设备管理

软件启动后应能够搜索本机连接的海康工业相机。

应至少提供：

- 搜索设备；
- 设备列表；
- 打开相机；
- 关闭相机；
- 开始采集；
- 停止采集；
- 相机异常断开检测；
- 相机重新连接。

设备信息至少显示：

- 相机型号；
- 序列号；
- 当前连接状态；
- 图像分辨率；
- 当前 Pixel Format；
- 当前实际采集帧率。

相机未连接时，与采集和参数设置相关的功能应处于不可用状态。

# 4. 相机像素格式与位深

软件不将位深简单写死为固定的 8 bit、10 bit 和 12 bit，而是通过海康 MVS SDK / GenICam 接口读取相机当前实际支持的 `PixelFormat`。

针对 MV-CH050-10UP，软件应考虑支持：

- Mono8；
- Mono10；
- Mono10 Packed / Mono10p；
- Mono12；
- Mono12 Packed / Mono12p。

最终下拉菜单中实际显示的项目以相机当前返回的可用枚举值为准。

内部处理原则：

### Mono8

使用 8 bit 无符号数据：

\[
0\sim255
\]

### Mono10

转换为至少 16 bit 无符号数据进行处理：

\[
0\sim1023
\]

### Mono12

转换为至少 16 bit 无符号数据进行处理：

\[
0\sim4095
\]

Packed 数据在进入偏振算法前首先正确解包。

**偏振参数必须根据相机原始有效位深数据计算，不允许先转换为 8 bit 显示图以后再进行偏振计算。**

# 6. 图像处理流程

完整实时处理链定义为：

**Camera RAW**

→ DoFP 四方向数据解析

→ 四方向全分辨率插值

→ Gray 计算

→ Stokes 参数计算

→ DoLP 计算

→ AoLP 计算

→ NaN 有效性判断

→ 显示映射

→ GUI 显示 / TIFF 保存

RAW、Gray、AoLP 和 DoLP 必须来源于同一个 Camera Frame ID。

避免不同页面显示的数据来自不同采集帧。

---

# 7. DoFP 原始偏振阵列解析

MV-CH050-10UP 使用焦平面分割式偏振传感器。

原始 RAW 图像中的相邻像素分别对应：

\[
0^\circ,\quad45^\circ,\quad90^\circ,\quad135^\circ
\]

四种线偏振方向。

程序应按照 MV-CH050-10UP / IMX250MZR 的实际偏振微阵列排列解析数据。

开发阶段必须通过相机实际输出和测试确认四种偏振方向在 2×2 单元中的具体位置。

这一对应关系属于底层算法定义，不作为普通用户参数开放。

---

# 8. 全分辨率偏振插值

软件采用：

## 同偏振方向的位置感知双线性插值

分别对四个偏振方向处理：

\[
I_0^m\rightarrow I_0
\]

\[
I_{45}^m\rightarrow I_{45}
\]

\[
I_{90}^m\rightarrow I_{90}
\]

\[
I_{135}^m\rightarrow I_{135}
\]

其中：

- \(I^m\) 表示传感器实际测量的稀疏偏振像素；
- \(I\) 表示经过插值得到的全分辨率偏振图。

最终生成四幅：

**2448 × 2048**

全分辨率偏振强度图像。

插值要求：

- 原始实测像素位置保持原始值；
- 缺失位置仅使用相同偏振方向的邻近采样点插值；
- 采用二维双线性插值；
- 考虑不同偏振方向的空间采样位置；
- 图像边缘采用合理的边界处理；
- 不允许跨图像循环插值；
- 插值过程使用原始线性灰度数据。

第一版不采用边缘感知、深度学习等复杂偏振 demosaic 算法。

# 10. 灰度图计算

在四方向偏振图完成全分辨率插值之后计算灰度图：

\[
Gray=
\frac{
I_0+I_{45}+I_{90}+I_{135}
}{4}
\]

灰度图分辨率：

**2448 × 2048**

灰度值内部保持与当前有效位深对应的数值范围。

例如：

Mono8：

\[
0\sim255
\]

Mono10：

\[
0\sim1023
\]

Mono12：

\[
0\sim4095
\]

屏幕显示时可映射到显示设备所需灰度范围，但不得改变内部定量数据。

---

# 11. Stokes 参数计算

使用插值后的四幅全分辨率偏振图计算：

\[
S_0=
\frac{
I_0+I_{45}+I_{90}+I_{135}
}{2}
\]

\[
S_1=I_0-I_{90}
\]

\[
S_2=I_{45}-I_{135}
\]

Stokes 参数以及后续偏振参数计算建议采用至少：

**32 bit floating point**

数据。

避免发生整数相减、平方或除法带来的溢出和精度损失。

---

# 12. 线偏振度 DoLP

线偏振度定义为：

\[
DoLP=
\frac{
\sqrt{S_1^2+S_2^2}
}{
S_0
}
\]

内部数值范围：

\[
0\sim1
\]

用户界面统一显示为：

\[
0\%\sim100\%
\]

例如内部：

\[
DoLP=0.423
\]

界面显示：

**42.3 %**

---

# 13. 线偏振角 AoLP

偏振角定义为：

\[
AoLP=
\frac{1}{2}
\operatorname{atan2}(S_2,S_1)
\]

换算为角度以后统一表示为：

\[
-90^\circ\le AoLP<90^\circ
\]

角度坐标规定：

- 图像水平向右，即图像 +X 方向，为 **0°**；
- 逆时针方向定义为正角度；
- 顺时针方向定义为负角度。

例如：

- 水平向右：0°；
- 逆时针 45°：+45°；
- 顺时针 45°：−45°；
- 垂直方向对应 ±90° 的周期边界。

---

# 14. 低信号 NaN 判定

为了避免低光强区域产生无物理意义的偏振角和偏振度，对每一个像素进行有效性判断。

首先计算：

\[
Gray=
\frac{
I_0+I_{45}+I_{90}+I_{135}
}{4}
\]

当前位深满量程定义为：

\[
FS=2^B-1
\]

其中 \(B\) 为当前有效位数。

固定低信号阈值：

\[
Gray<2\%FS
\]

即：

\[
\frac{Gray}{FS}<0.02
\]

时，将当前像素：

\[
DoLP=NaN
\]

\[
AoLP=NaN
\]

灰度图本身仍然显示实际灰度值，不变为 NaN。

该 **2%FS** 为 V1.0 固定默认有效性规则。

其优势是切换 Mono8、Mono10、Mono12 后自动适配实际有效位深。

---

# 15. 基于 DoLP 的 AoLP 有效性判断

由于偏振度非常低时 AoLP 的物理意义较弱，软件增加：

**Minimum DoLP for Valid AoLP**

功能。

设置页面包括：

- Enable / Disable；
- Minimum DoLP Threshold。

当功能关闭时：

只使用 2%FS 灰度条件判断 AoLP 是否有效。

当功能开启，并且：

\[
DoLP<T_{DoLP}
\]

时：

\[
AoLP=NaN
\]

但 DoLP 本身仍正常显示。

该参数使用百分比表示，例如：

`Minimum DoLP = 5%`

阈值允许用户修改。

开关状态和用户设定值在软件退出后保存。

V1.0 默认可设置为：

**Disable**

即默认不额外根据 DoLP 删除 AoLP 数据，由用户根据实验需要主动开启。

---

# 16. NaN 显示规则

AoLP 和 DoLP 伪彩色图中的 NaN 像素统一显示为：

**中性灰色**

建议：

`RGB(128,128,128)`

NaN 灰色必须与正常伪彩色色标明显区分。

Color Bar 中注明：

**Gray = Invalid / NaN**

鼠标移动到 NaN 像素时显示：

`Gray = xxxx DN`

`AoLP = NaN`

`DoLP = NaN`

不得将 NaN 显示为：

- 0°；
- 0%；
- 最低色标颜色。

保存浮点 TIFF 时应保存真正的 IEEE NaN。

---

# 17. AoLP 伪彩色显示

AoLP 使用周期性伪彩色色图。

显示范围固定为：

\[
-90^\circ\sim+90^\circ
\]

由于线偏振方向具有：

\[
-90^\circ\equiv+90^\circ
\]

的周期关系，因此色图两端颜色应连续或相同。

AoLP 页面显示：

- 伪彩色图；
- Color Bar；
- 最小值 −90°；
- 中间值 0°；
- 最大值 +90°；
- NaN 灰色说明。

伪彩色仅影响显示，不影响定量数据。

---

# 18. DoLP 伪彩色显示

DoLP 使用连续伪彩色色图。

建议采用具有较好定量可读性的连续色图，例如 Viridis 类色图。

显示范围固定为：

\[
0\%\sim100\%
\]

DoLP 页面显示：

- 伪彩色图；
- Color Bar；
- 0%；
- 100%；
- NaN 灰色说明。

---

提供两种模式。

## 22.1 总体灰度模式

统计最终 Gray 图：

\[
Gray=
\frac{I_0+I_{45}+I_{90}+I_{135}}{4}
\]

横坐标使用当前原始有效 DN 范围。

例如：

Mono8：

\[
0\sim255
\]

Mono10：

\[
0\sim1023
\]

Mono12：

\[
0\sim4095
\]

纵坐标表示：

**对应灰度值的像素数量。**

---

## 22.2 四偏振方向模式

分别显示：

- 0°；
- 45°；
- 90°；
- 135°；

四个灰度直方图。

推荐界面：

```text
┌─────────────┬─────────────┐
│     0°      │     45°     │
├─────────────┼─────────────┤
│     90°     │    135°     │

```

四方向直方图优先统计对应偏振方向的**原始实际采样数据**，而不是插值生成的像素，以避免插值过程人为改变灰度分布。

该模式下：

- 无需外部触发信号；

- 实时计算 Gray、AoLP、DoLP；

# 27. 外部硬件触发

外部触发模式下，应提供尽可能完整的触发参数。

## Trigger Mode

- Off / Free Run；
- On / Triggered。

## Trigger Source

以相机实际支持节点为准，例如：

- Software；
- Line0；
- Line2；
- 其他相机支持的 Trigger Source。

## Trigger Activation

以当前相机支持项为准，例如：

- Rising Edge；
- Falling Edge；
- Level High；
- Level Low；
- Any Edge。

## Trigger Delay

提供：

**Trigger Delay**

设置。

单位优先显示为：

**μs**

同时显示：

- 当前值；
- 最小值；
- 最大值；
- 步进值。

## Burst Frame Count

如果当前相机支持：

**Acquisition Burst Frame Count**

则允许设置一次触发采集多帧。

默认值：

**1**

即一次外触发对应一帧。

## Trigger Cache

如果相机支持 Trigger Cache，则提供开启/关闭选项。

## Line Debouncer

如果相机支持硬件输入去抖功能，则提供：

**Line Debouncer Time**

设置。

单位：

**μs**

用于避免短时间毛刺造成误触发。

所有相机不支持的触发参数自动隐藏或禁用。

# 28. 外部触发状态显示

- External Trigger；

- Trigger Received；

- 当前 Trigger Source；
- Trigger Delay；

- 当前帧率。

当相机正在等待外部触发信号时，应明确显示：

**WAITING FOR TRIGGER**

避免用户误认为软件停止响应。

# 29. 实时帧率显示

主界面或状态栏实时显示实际采集帧率。

至少显示：

**Acquisition FPS**

建议同时区分：

- Camera / Receive FPS；
- Processing FPS；
- Display FPS。

例如：

`Receive 74.0 fps | Process 73.5 fps | Display 59.8 fps`

如果最终只显示一个 FPS，应优先显示：

**相机实际成功接收帧率。**

---

# 30. 实时性能要求

软件性能目标为：

> 在计算机性能、Pixel Format、曝光时间和 USB 带宽允许的条件下，尽可能接近相机允许的最高实时采集帧率。

相机采集不得因为 GUI 刷新而长时间阻塞。

推荐内部采用独立的数据处理流程：

**采集**

→ **偏振计算**

→ **显示**

→ **保存**

显示速度低于采集速度时，可以适当跳过 GUI 显示帧，但不得无提示地影响相机采集。

图像保存也不得长时间阻塞采集线程。

---

# 31. 手动 TIFF 保存

用户点击：

**Save Image**

时，保存：

> 当前屏幕正在显示的页面所对应的当前帧。

例如：

当前位于 RAW 页面：

→ 保存 RAW TIFF。

当前位于 Gray 页面：

→ 保存 Gray TIFF。

当前位于 AoLP 页面：

→ 保存 AoLP TIFF。

当前位于 DoLP 页面：

→ 保存 DoLP TIFF。

保存操作必须针对当前显示的 Frame ID，而不能在用户点击保存后重新取得另外一帧。

---

# 32. TIFF 数据格式

## RAW

Mono8：

保存为：

**8-bit unsigned TIFF**

Mono10 / Mono10Packed：

保存为：

**16-bit unsigned TIFF**

实际有效范围：

\[
0\sim1023
\]

Mono12 / Mono12Packed：

保存为：

**16-bit unsigned TIFF**

实际有效范围：

\[
0\sim4095
\]

Packed 数据保存 TIFF 时不需要继续保持 Packed 存储。

---

## Gray

Mono8 来源数据：

可保存为 8-bit TIFF。

Mono10、Mono12 来源数据：

保存为 16-bit TIFF。

Gray 数据按实际计算结果进行合理四舍五入或转换。

---

## AoLP

保存为：

**32-bit floating-point TIFF**

单位：

**degree**

数值范围：

\[
-90^\circ\sim90^\circ
\]

无效位置保存真正的：

**NaN**

而不是灰色 RGB 值。

---

## DoLP

保存为：

**32-bit floating-point TIFF**

内部数值范围：

\[
0\sim1
\]

无效位置保存：

**NaN**

界面显示的百分比格式不改变 TIFF 中的数值定义。

---

# 33. 伪彩色与 TIFF 的关系

AoLP 和 DoLP 屏幕显示使用伪彩色。

但 TIFF 默认保存的是：

**原始定量数据**

而不是屏幕上的 RGB 伪彩图。

即：

AoLP TIFF 保存实际角度值；

DoLP TIFF 保存实际 0～1 浮点值。

这样保证后续 MATLAB、Python、Origin 等软件能够继续进行定量分析。

---

# 34. 外部触发自动保存

增加设置：

**Auto Save on External Trigger**

可选择：

- Enable；
- Disable。

默认：

**Disable**

开启以后，每次收到有效外部触发并成功获得一帧图像后，自动保存该帧。

自动保存内容与当前选定的图像页面对应：

- RAW 页面 → 自动保存 RAW；
- Gray 页面 → 自动保存 Gray；
- AoLP 页面 → 自动保存 AoLP；
- DoLP 页面 → 自动保存 DoLP。

保存路径由用户提前设置。

文件名应自动包含时间和连续编号，避免覆盖已有数据。

例如：

`20260928_193012_123_Frame000125_AoLP.tif`

---

# 35. 保存参数和文件命名

设置页面应允许选择：

- 保存目录；
- 文件名前缀；
- 是否加入时间戳。

自动保存必须确保文件名唯一。

保存失败时应显示明确错误，不得静默丢失图像。

---

# 36. 图像参数关联

当前屏幕显示的 RAW、Gray、AoLP 和 DoLP 数据必须关联：

- Frame ID；
- Timestamp；
- Pixel Format；
- Exposure Time；
- Gain；
- Trigger Mode；
- Trigger Source。

以确保保存的数据能够对应当时实际的相机采集条件。

---

# 37. 显示处理与定量处理分离

所有偏振计算必须使用：

**线性的原始图像数据。**

以下处理如果以后用于改善屏幕显示，只允许作用于显示层：

- Gamma；
- Contrast；
- LUT；
- 自动拉伸；
- 伪彩色；
- 锐化；
- 显示降噪。

这些显示处理不得参与：

- Gray 计算；
- Stokes 计算；
- AoLP 计算；
- DoLP 计算；
- TIFF 定量数据保存。

# 43. V1.0 核心验收要求

软件完成后至少应满足以下条件。

## 相机控制

能够正常连接 MV-CH050-10UP，并设置：

- Exposure；
- Gain；
- Pixel Format；
- 内部采集；
- 软件触发；
- 外部触发；
- Trigger Delay。

---

## RAW 显示

能够实时显示：

**2448 × 2048 RAW DoFP 图像。**

---

## Gray

能够按照同方向双线性插值后：

\[
Gray=
\frac{I_0+I_{45}+I_{90}+I_{135}}{4}
\]

实时生成：

**2448 × 2048 Gray 图。**

---

## DoLP

能够实时计算：

\[
DoLP=
\frac{\sqrt{S_1^2+S_2^2}}{S_0}
\]

并以：

**0～100%**

伪彩色显示。

---

## AoLP

能够实时计算：

\[
AoLP=
\frac12\operatorname{atan2}(S_2,S_1)
\]

并以：

\[
-90^\circ\sim90^\circ
\]

周期伪彩色显示。

0°对应图像水平向右。

---

## NaN

当：

\[
Gray<2\%FS
\]

时：

AoLP = NaN；

DoLP = NaN。

伪彩图使用中性灰色表示 NaN。

---

## DoLP 阈值

能够开启或关闭：

**Minimum DoLP for Valid AoLP**

并能够修改阈值。

---

## 鼠标查询

鼠标放置在 Gray、AoLP、DoLP 任意图像上时，可以正确显示：

- X；
- Y；
- Gray；
- AoLP；
- DoLP。

---

## 图像缩放

所有图像页面均可：

- 放大；
- 缩小；
- 平移；
- Fit；
- 1:1。

---

## 直方图

能够实时显示：

- 总体 Gray Histogram；

以及：

- 0°；
- 45°；
- 90°；
- 135°；

四方向 Histogram。

两种模式可以切换。

---

## 帧率

实时显示实际采集 FPS，并在计算机性能允许情况下尽可能接近当前相机最大可用采集速度。

---

## TIFF

能够根据当前页面正确保存：

- RAW TIFF；
- Gray TIFF；
- AoLP Float TIFF；
- DoLP Float TIFF。

NaN 数据必须正确保留。

---

## 外部触发自动保存

开启功能后，每次有效外触发采集成功，可以自动保存对应当前显示页面的 TIFF 图像。
