## 计算基准

使用确定性生成的 2448×2048 uint16 / 12 bit 原始帧，预热后每组 6 次；包括四方向全分辨率插值、Gray、AoLP、DoLP、五组精确直方图。最终基准数据见 `benchmark.json`。

在该主机上，16 个计算线程的中位时间约 **36.5 ms / 帧（27.4 fps）**。不含相机传输、GUI 和磁盘，不能视为真实相机端到端帧率。接收与处理分离，预览处理跟不上时会明确累计预览跳过数量。
